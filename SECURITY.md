# Security Policy / Güvenlik Politikası

---

## 🇹🇷 Türkçe Güvenlik Politikası

Projemizin güvenliğini korumak bizim için çok önemlidir. TLC_egitim projesinde bir güvenlik açığı bulursanız, bunu kamuya açık bir hata kaydı (issue) olarak açmak yerine, doğrudan sorumlu bir şekilde bildirmek için lütfen aşağıdaki adımları izleyin.

### Desteklenen Sürümler
Şu anda yalnızca en son yayınlanan ana sürüm (main branch) aktif olarak güvenlik güncellemeleri almaktadır.

### Güvenlik Açığı Bildirimi
Eğer bu projede bir güvenlik açığı bulursanız:
1. Lütfen açığı kamuya açık bir alanda (GitHub Issues vb.) **kesinlikle paylaşmayın**.
2. Doğrudan depo yöneticisine (Yusuf Özdaş) e-posta veya özel mesaj yoluyla ulaşın.
3. Bildiriminizde, açığın nasıl sömürülebileceğini (exploit) ve yeniden üretilebileceğini detaylarıyla açıklayın.
4. Bildirilen açıklar en kısa sürede incelenecek ve gerekli düzeltmeler yapılarak yeni bir yama yayınlanacaktır.

## 🇬🇧 English Security Policy

Securing this project is of paramount importance. If you discover a security vulnerability within TLC_egitim, please follow the steps below to report it responsibly, rather than opening a public issue.

### Supported Versions
Only the latest active release on our `main` branch is actively supported with security updates.

### Reporting a Vulnerability
If you find a security vulnerability:
1. **Do not** report security vulnerabilities in public GitHub issues.
2. Reach out directly to the repository owner (Yusuf Özdaş) via email or private message.
3. In your report, please provide detailed steps to reproduce and exploit the vulnerability.
4. We will investigate the issue as quickly as possible and publish a fix/patch promptly.
